# Frontend Angular

Activar para frontend/, PWA y UI compartida web/escritorio/móvil.

- Diseñar por features y estados; evitar componentes gigantes.
- Reutilizar lógica/UI y aislar adaptadores nativos.
- UI no calcula totales fiscales, stock canónico ni permisos.
- Estados obligatorios según flujo: loading, vacío, error, éxito, denegado, offline y desactualizado.
- POS prioriza teclado, escáner, foco, pocos pasos y feedback inmediato.
- Responsive real y accesibilidad básica.
- Formularios con labels visibles y errores próximos al campo.
- No mostrar dato pendiente como cero.
- Secretos/certificados nunca en bundle.

Validación: flujo, móvil/escritorio, teclado cuando aplique y estados relevantes.
